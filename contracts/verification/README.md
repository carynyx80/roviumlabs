# Verifying an agent token on the Robinhood Chain explorer

Every token launched from RoviumPad is the same `RoviumAgentToken` contract, so its source can be verified on
[Blockscout](https://robinhoodchain.blockscout.com) (mainnet) or the
[testnet explorer](https://explorer.testnet.chain.robinhood.com) in a minute. Verification lets anyone read the code
and confirm the token has no owner, minting, fees or upgradeability.

1. Open your token's address on the explorer (the link is on the agent's **Token** page) → **Contract** → **Verify & publish**.
2. Choose **Solidity (Standard JSON input)**.
3. Compiler: **v0.8.28+commit.7893614a**. Contract name: `contracts/RoviumAgentToken.sol:RoviumAgentToken`.
4. Upload [`RoviumAgentToken.standard-input.json`](./RoviumAgentToken.standard-input.json) (optimizer 200 runs, EVM `paris`).
5. Constructor arguments are detected automatically from the deployment transaction. Submit.

The JSON file is generated by `npm run contracts:compile`; regenerate and re-commit it whenever the contract changes.
RoviumPad cannot verify automatically: the explorer API sits behind a bot-protection challenge.
